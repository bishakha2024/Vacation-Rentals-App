# Vacation Rentals App

## Overview
An Android application that allows property owners to list vacation rentals and enables travelers to browse properties.

## Features
- User Authentication (Firebase)
- Add Property Listings
- View All Listings
- Search Properties
- Google Maps Integration
- RecyclerView for Dynamic Data Display

## Technologies Used
- Kotlin
- Android Studio
- Firebase Authentication
- Cloud Firestore
- Google Maps API
- RecyclerView
- XML
